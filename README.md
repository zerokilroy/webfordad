# Metalworks — Высокоточная металлообработка

Современный и красивый веб-сайт для компании, специализирующейся на высокоточной металлообработке на ЧПУ-станках.

## 🎨 Особенности

✨ **Плавные анимации и переходы**
- Элементы появляются с анимациями при загрузке страницы
- Скролл-анимации при прокрутке страницы
- Плавные переходы между блоками
- Эффект "расшатывания" элементов списка

🎯 **Интерактивные элементы**
- Все кнопки работают с плавным скроллом к нужному разделу
- Навигационная панель меняется при наведении
- Карточки услуг и оборудования имеют эффекты наведения
- Мобильное меню с анимацией

🎭 **Дизайн**
- Респонсивный дизайн (мобильные, планшеты, десктопы)
- Индустриальная палитра цветов (синий, голубой, серый)
- Металлическая текстура как фон
- Сетка как фон в некоторых секциях

📱 **Полноценный контакт**
- Форма обратной связи с полями для загрузки чертежей
- Информация о контактах
- Режим работы
- Карта (placeholder)

## 🛠️ Технологический стек

- **React 18** — UI-библиотека
- **TypeScript** — типизированный JavaScript
- **Tailwind CSS** — утилитарное CSS
- **Vite** — быстрый сборщик
- **Lucide React** — иконки

## 🚀 Запуск проекта

### Требования
- Node.js 18+
- npm или yarn

### Установка и запуск

```bash
# Установка зависимостей
npm install

# Запуск dev сервера
npm run dev

# Сборка для продакшена
npm run build
```

После выполнения `npm run dev` откройте браузер на `http://localhost:5173`

## 🎨 Анимации

Проект использует следующие типы анимаций:

- **Fade In** — появление элемента (opacity: 0 → 1)
- **Fade In Up** — появление с поднятием (translateY: 30px → 0)
- **Fade In Left/Right** — появление со смещением по горизонтали
- **Scale In** — появление с масштабированием
- **Slide Up** — скольжение вверх
- **Stagger** — каскадная анимация для списков
- **Glow Pulse** — пульсирующий блеск (для кнопок)

## 📱 Главные секции

1. **Header/Navigation** — Фиксированная навигация с плавным переходом
2. **Hero** — Главная секция с заголовком и преимуществами
3. **Services** — 6 услуг с карточками
4. **About** — Статистика и особенности
5. **Equipment** — Парк оборудования
6. **Process** — 4 этапа работы
7. **Contact** — Форма обратной связи и контакты
8. **Footer** — Подвал с информацией
